# 岡崎 みんなのワールド — 先生・生徒の使い方（1.8）

公開URL: https://metaquest001.gigach.net/

## 先生の準備

1. 「ログイン」から登録済みの先生のGoogleアカウントで入ります。初回は表示名を決めます。教室選択はありません。
2. 「発行する人数」を入力し「ID・パスワードを発行」。発行済みを含め最大30人です。
3. 表示された情報を安全に控え、各生徒には本人のID・パスワード1組と上記URLだけを渡します。全員のパスワードをクラス全体に公開しないでください。パスワードは再表示できません。
4. 忘れた生徒は「生徒一覧を確認」からパスワードを再発行できます。旧パスワードと旧セッションは無効になりますが、名前・アバター・STL・配置は残ります。

登録済みの先生は同じワールドの保存・復元・ID管理を共同で行えます。最大30人の生徒＋4人の先生が接続できます。生徒枠の削除・再割当ては未対応です。同じIDを別の生徒に渡すと元の人の作品の所有者になるため、使い回さないでください。

## 生徒の入り方

1. URLを開き「ログイン」の「生徒：IDで入る」にID・パスワードを入力します。
2. 初めてだけ、頭の上に表示する名前を決めて「この名前でワールドに入る」を押します。本名ではなく授業用のニックネームを推奨します。先生・生徒で同じ名前は使えません（前後の空白と英字の大文字・小文字は区別しません）。
3. 自動で「岡崎 みんなのワールド」に参加します。次回も同じIDを使います。Googleアカウントや招待コードは不要です。

同じIDを複数端末で使うと最後に接続した端末に活動が移ります。閲覧のみならログイン不要ですが、他の参加者や共有作品の取得・配置にはログインが必要です。

次回は同じID・パスワードだけで、保存した名前・色・STL・配置位置・回転・大きさを読み込みます。配置はサーバーの受理後に自動保存され、ログアウトしても消えません。まだ配置を確定していない下書きは保存されません。先生が過去のワールドを復元した場合は、その時点の配置になります。自分の作品だけを操作できます。

1.9.3より前に同じ名前が登録されていた場合は、先に登録されたアカウントを優先し、他のアカウントには新しい名前の入力を案内します。ID・パスワード・作品はそのままです。新しいIDを発行し直す必要はありません。

## PCの基本操作

| 操作 | 方法 |
| --- | --- |
| 移動・見回す | 画面をクリック、W/A/S/D＋マウス |
| 高速移動 | 同じW/A/S/Dを2回押し、2回目を保持。またはCtrl |
| 飛行時の上下 | Spaceで上昇、Shiftで下降 |
| 飛行／歩行 | Spaceを2回押す |
| 視点 | 最初は三人称・後方。F5で後方→前方→一人称 |
| メニュー | Escで右メニューを開閉。3D画面クリックで閉じる |
| STL選択 | 画面下の10枠、または1〜9・0 |
| 配置 | 空いている地面をねらい、左クリック |
| 見回す（STLを持っていても可） | 3D画面を右ドラッグ。地面・空で操作は変わりません |
| 設置前のサイズ | 3D画面上でホイールを上に回すと拡大、下で縮小 |
| 回収 | 自分の作品をねらい、Rキーを押す |

マウス固定をブラウザが許可しない場合も、通常のカーソルで位置を選んで置けます。入力はメニューや入力フォームを開いている間停止します。画面クリックでPCのクリエイティブ移動を再開します。壁の厳密な衝突はありません。

## STLを置く

一人称では画面右下に自分の右腕と手を表示します。STLを選ぶと手のひらに小さな模型を持ち、配置・キャンセル後は空手に戻ります。肌・袖は自分のアバターの色です。この腕はPC・スマホの自分の画面だけの表示で、VR中には表示しません。

空のホットバー枠をクリックしてファイルを選びます。複数選択も可能です。先頭の空き枠から順に入り、最長辺10m・CADのZ軸を上として読み込みます。単位・上方向が異なる場合は「自分のSTL作品」で設定してから読み込んでください。

PC・スマホでは、選択した未配置STLを自分の手元に小さく表示します。手元の模型は選択確認用で、設置サイズは変えません。地面の半透明プレビューと緑／赤の底面を確認して配置すると、手元から消えます。キャンセル・ログアウト時も消えます。見学中は仮アバターを表示しますが、作品の配置にはログインが必要です。VRでは本人視点と既存の作品パネルを使います。

1枠につき1作品を設置できます。配置前に半透明の模型と、実地面に沿った底面の影が表示されます。緑は配置可能、赤は建物との重なり等で配置不可です。空・地形のない場所・建物の奥には置けません。設置後の枠は「設置済」。Rキーで回収すると「置けます」に戻り、枠を選んで置き直せます。右クリックでは回収しません。他人の作品や建物の奥にある作品は回収できません。

ホイールは設置前の自分のSTLだけを縦横比を保って拡大縮小します。地面のプレビューと幅・高さ・奥行き（m）を確認してください。手元は視界を遮らない小さな見本のままです。大きくして建物と重なった場合などは赤くなり、配置できません。メニュー・VR中・設置後にはホイールで作品は変わりません。Ctrl／Command＋ホイールはブラウザの操作を優先します。

回転・数値での拡大縮小は「自分のSTL作品」の詳細操作で行えます。X/Y/Z回転と縮尺を変更し、配置を確定してください。回収は配置だけを取り消し、STL原本はクラウドに残します。先生も含め、他人の作品を直接変更・回収できません。元の街も変更しません。

上限: 1人10ファイル・合計25MiB、1ファイル6MiB・2万三角形。1人の同時配置は10点。ワールド全体は最大340点ですが、全作品合計20万三角形の制限が先に適用されることがあります。大きさは各方向100mまで。全員が10点ずつ重い模型を置ける保証ではありません。

## 保存・再開

確定した作品は随時クラウド保存されます。先生の「授業の状態を保存」は全員の位置・作品の復元ポイントです。「復元」は全員の状態を巻き戻すので、授業中に声をかけてから実施してください。最新20件を保持します。

1.8の共通ワールドは新設です。旧版の個別ワールド・作品・復元ポイントは削除せず保管しますが、新画面に自動統合しません。旧データの移行は所有者や配置の衝突を確認して別途実施します。

## Quest・スマホ

Questのブラウザでも同じURL・IDを使います。ログインやファイル選択は2Dで行い、メニューからVRへ入ります。VRは既存の中央パネルの「作品」で配置・回転・縮尺を操作します。PCホットバーやマウス操作をVRに重ねません。中央の「2Dに戻る」またはXの1.5秒長押しで戻れます。移動はBで開始・停止し、左スティック上下＝昇降／左右＝旋回、右スティック＝前後左右のモード2です。

スマホは下部の「見学」「広域」「設定」と仮想スティックを利用します。STLの詳細操作も利用できます。PCのRキーによる回収をタッチ長押しとして扱うことはしません。

## 授業前の確認

学校のネットワーク・利用規定に従い、少人数でログイン、読み込み、配置、回収、再開を試してから30台で確認してください。自動試験の34接続は実教室の通信速度やQuestの快適性を保証しません。重い場合は画質を下げ、STLを簡略化します。VRの年齢条件・安全なスペース・監督・不快感時の中止を守ってください。パスキー・音声会話・チャット・アカウント自己削除は未実装です。
