# 岡崎駅 フィールドノート 1.7 — 先生・生徒の共同教室ガイド

このガイドはWeb版の共同教室機能の使い方です。公開URLは [https://metaquest001.gigach.net/](https://metaquest001.gigach.net/) です。開発中の機能がすべて本番へ公開されたという意味ではありません。公開コミット・実施した試験・未確認項目は [VALIDATION.md](../VALIDATION.md) で確認してください。

街の3D・VR閲覧はGoogleログインなしで使えます。作品の読み込み・配置、ほかの参加者とアバターで活動するには **Googleログインと教室への参加**が必要です。元のPLATEAUの街は変更せず、授業で作った作品を別のレイヤーとして加えます。

## 1. 授業の始め方

| 先生がすること | 生徒がすること |
|---|---|
| 2D画面でGoogleログインし、自分の教室を作る | 先生から招待URLまたは12文字の参加コードを受け取る |
| 教室の「招待URLをコピー」でURLを配る | URLを開き、2D画面で学校が許可したGoogleアカウントでログインする |
| 自分も教室へ接続する | 「この教室に参加」を押す。URLを開くだけでは参加しない |
| 先生と生徒のアバター、作品を確認する | 自分のSTLを読み込み、2DまたはVRで配置する |
| 授業の最後に「授業の状態を保存」を押す | 次回も同じGoogleアカウントでログインし、「続きを開く」で再開する |

先生1人と生徒30人、最大31人を想定しています。これはサーバー側の上限で、全端末で滑らかに動く保証ではありません。教室への生徒登録にも30人の上限があります。退出・ログアウトだけでは登録や作品は消えません。登録した生徒の削除、参加コードの変更、教室の完全削除は現在の画面にはありません。

## 2. 先生：教室を作って配る

1. 公開URLを2Dブラウザで開き、画面の「共同教室 / ログイン」を押します。QuestのVR中なら先に中央パネルの「2Dに戻る」で戻ります。
2. 「Googleログインを表示」を押し、Googleのボタンからログインします。先生として事前登録されたアカウントでログインすると「先生としてログイン中」と表示されます。表示だけを変更しても先生権限は得られません。
3. Googleの確認画面に「教職員異動検索」と表示される場合があります。既存のGoogle Cloudプロジェクトの共通アプリ名を利用しているためです。本アプリは基本的な本人確認だけを行い、Gmail・Driveを読んだり、Googleのパスワードを受け取ったりはしません。
4. 「新しい教室の名前」を入力して「教室を作成」を押します。個人情報を教室名へ入れないでください。先生1アカウントにつき最大10教室です。
5. 「現在の教室」に参加コードと配布用URLが出ます。「招待URLをコピー」でClassroomなどへ配ります。コピーできない場合は、選択されたURL欄をブラウザのコピー操作でコピーします。
6. 「接続中：共同活動できます」を確認します。接続待ち・再接続中は配置を確定できません。

招待URLの例は `https://metaquest001.gigach.net/#join=ABCDEFGHIJKL` です。例のコードは授業用コードではありません。実際に作成された教室のコードを使ってください。コードは対象の生徒だけへ配り、公開ページへ掲載しないでください。コードを知るGoogleログイン済みの人を学校の名簿で自動照合する機能はありません。

先生は、自分が作成した教室だけを管理できます。別の先生の教室を共同管理する機能は未実装です。

## 3. 生徒：教室に参加する

1. 先生から受け取ったURLを開きます。コードだけの場合は公開URLを開きます。街を見るだけならここでログインする必要はありません。
2. 「共同教室 / ログイン」→「Googleログインを表示」からログインします。学校が許可した学校のGoogleアカウント、またはGmailを使います。
3. 招待URLで開いた場合はコードが入力済みになります。そうでない場合は先生から受け取った12文字のコード、または招待URL全体を入力します。
4. 「この教室に参加」を押します。「接続中：共同活動できます」と表示されたら参加完了です。
5. アバターの名前・色を変えたい場合は、「アバターを保存」を押します。初期名は自動生成のニックネームです。Googleの氏名・写真・メールアドレスをそのまま参加者表示へ出しません。アバター名にも本名・住所・メールアドレスを入れないでください。

同じ教室のほかの参加者は、オリジナルのブロック風アバターとニックネームで見えます。マイクによる音声会話やチャットはありません。学校のGoogle管理者によって外部アプリへのログインが制限される場合は、先生・校内管理者がアプリの許可設定を確認してください。生徒のパスワードや認証コードを先生や開発者へ送る必要はありません。

## 4. 自分のSTL作品を読み込む

ファイル選択は2D画面で行います。Quest内の標準ファイル選択が操作しづらい場合は、同じGoogleアカウントでPCから同じ教室へ入り、読み込んでからQuestでその教室を開けます。ただし同じアカウントで同じ教室に同時接続すると、あとから接続した端末へ活動が切り替わり、先の端末は停止します。

1. 教室へ参加した状態で「STL作品」を開きます。
2. CADの上方向を「Z軸」または「Y軸」から選びます。多くのCADではZ軸です。
3. STLに単位情報はないため、「最長辺を10mに合わせる」「元データはmm」「元データはm」を正しく選びます。
4. ASCIIまたはバイナリSTLを読み込みます。複数のファイル・作品を扱えますが、編集する下書きは1つずつです。アップロード済みの自分のSTLは再利用できます。
5. 読み込みが成功するとSTL本体はクラウドへ保存されます。まだ配置を確定していない場合も、アップロードしたファイルは保存済みです。

上限は次のとおりです。複雑な作品はCADで簡略化して書き出してください。

| 対象 | 上限 |
|---|---:|
| STL 1ファイル | 6MiB、20,000三角形 |
| 1人・1教室のアップロード済みSTL | 10ファイル、合計25MiB |
| 教室全体の配置済み作品 | 120点、合計200,000三角形 |
| 配置後の作品の大きさ | X・Y・Z各方向100mまで |

破損、非有限座標、面積のない三角形などは拒否します。STLには色・テクスチャ情報がないので作品は単色表示です。秘密情報、他人の個人情報、配布する権利のない作品はアップロードしないでください。同じ教室の参加者は表示のためSTLを取得できます。

## 5. 2D画面で配置・回転・拡大縮小

1. 自分のSTLまたは作品を選びます。他の人の作品は見えますが、変更・削除できません。先生も生徒の作品を直接編集できません。
2. 東西X・南北Z、縮尺、X・Y・Z各軸の回転角を調整します。回転は全方向に指定できます。
3. 「地面をクリックして移動」を使うと、街の地面をクリックして配置位置を選べます。底面の高さは実際の地形へ自動で合わせます。
4. 赤い作品は未確定または配置不可の下書きです。元の建物・既存作品への重なり、地面が確認できない場所、配置範囲外などでは確定できません。
5. 「配置を確定」を押します。サーバーで実地形・建物・所有者・最新の変更番号を検査して成功した作品だけが、ほかの参加者へ共有されます。

配置できるのは、駅周辺の実地形と元の建物を確認できる範囲です。広域の閲覧範囲すべてへ配置できるわけではありません。判定は安全側なので、見た目に空いている細い隙間や斜面でも置けない場合があります。架空の平らな地面へ置き換えることはしません。

下書きの変更は他人に共有しません。「作品を削除」は配置を削除する操作で、アップロードしたSTL本体をR2から消す機能ではありません。クラウドへの通信が切れた場合や、別の参加者が先に変更した場合は処理を止めて状態を読み直します。自動で他人の変更を上書きしません。

## 6. QuestのVR内で配置する

1. 2D画面でGoogleログインし、先生の教室へ参加し、使うSTLを読み込みます。
2. 「VRで見る」または「VRに戻る」を押します。ログインしていない場合も街のVR閲覧はできますが、作品の操作や共有アバター活動はできません。
3. VR内の中央パネルで「作品」を選びます。左は水色・右はオレンジの光線です。先端の丸い目印を大きなボタンへ合わせ、枠が光ったら、その手のトリガーを1回押します。左右どちらでも使え、両手で別のボタンを狙った場合もそれぞれの照準を表示します。灰色の目印やボタンの隙間では操作できません。押したままで繰り返し実行したり、見つめるだけで選択したりはしません。
4. 左右の矢印で自分のSTLを選びます。X・Y・Zの「−15°」「＋15°」で回転し、「縮小×0.9」「拡大×1.1」で大きさを変えます。
5. 「地面を指して配置」を選び、地面へ光線を合わせてトリガーを押します。
6. 配置可能な下書きで「配置を確定・共有」を押します。やめる場合は「下書きを取消」を選びます。

新しいファイルの選択やGoogleログインは、VR内の3Dパネルでは行いません。中央パネルの「2Dに戻る」をトリガーで押すか、左コントローラーのXを1.5秒押し続けて2Dブラウザへ戻ります。ページの再読み込みはしません。短いX操作は同じパネルの内容の折りたたみ・展開で、2D復帰のボタンは残ります。

VRでは「岡崎まち フィールドノート」の1枚に案内・2D復帰・左右コントローラー状態をまとめます。「見学」「広域」「作品」を切り替えても別の固定パネルは増えません。街を広く見たいときはXを短く押して内容を折りたたんでください。PC画面の左右下のコントローラープレビューは従来どおりです。

VRから2Dへ戻ると自由移動はOFFです。再入場後も最初は停止しているので、周囲を確認してからBで移動をONにしてください。動きが重い、不快に感じる場合は使用を止め、画質を標準・軽量へ変えてください。

## 7. PC・スマホ・Questの移動

PCの初回は「クリエイティブ風」・自由移動ONです。「見学」タブの先頭で操作モードと自由移動ON/OFFを切り替えます。3D画面をクリックするとマウスで見回せますが、最初からマウスを固定したり自動で移動したりはしません。選んだモードは次回も使い、従来のドローンにも切り替えられます。モード・地点の切替、先生による共有位置の復元、ダイアログ、画面から離れたとき、VR入退場では移動OFFになります。読み込み中に画面を離れた場合も勝手にONへ戻しません。再開するときは「見学」の自由移動を改めてONにしてください。

| PCクリエイティブ風 | 操作 |
|---|---|
| W・A・S・D | 前後左右 |
| 同じW/A/S/Dを350ms以内に二度押しし、2回目を保持 | 保持中は1.5倍速。離すと解除 |
| Ctrlを保持 | 1.5倍速。二度押しと重ねても倍率を重ねない |
| Space / Shift | 飛行中の上昇 / 下降 |
| Spaceを二度押し | 飛行 / 歩行の切り替え |
| 歩行中のSpace | 地面が確認できる場所でジャンプ |
| F5 | 一人称 → アバター後方 → 前方。ページ再読み込みはしない |
| Esc | マウスの見回しを解除 |

歩行は実地形の高さを使いますが、厳密な建物・壁の衝突は未実装です。操作フォーム・ダイアログを開く、画面が非表示になる、VRへ切り替えると入力を停止します。ドローン操作のPCショートカットはWASDで前後左右、R/Fで上下、Q/Eで旋回です。

スマホ・Questは従来のドローンモード2です。左スティックが上下移動・旋回、右スティックが前後・横移動です。倒し量に応じて速度が変わり、保持時間では加速しません。Bで自由移動ON/OFF、Yで駅へ戻ります。スマホは仮想スティックで、指を離すと停止します。VRの視点はプレイヤーの眼を基準にし、PCの後方カメラの位置から入場しません。

## 8. 先生：保存し、次回から続ける

作品を確定・変更・削除した状態は、サーバーで成功すると随時保存されます。先生の「授業の状態を保存」は、全員の作品とその時点のアバター位置を復元ポイントとして残します。

1. 授業の最後に2D画面の共同教室を開き、「授業の状態を保存」を押します。
2. 次回は同じGoogleアカウントでログインし、「以前に参加した教室」で同じ教室を選んで「続きを開く」を押します。ログインしただけでは自動参加しません。
3. 同じアカウントのアバター、参加教室、自分がアップロードしたSTL、確定済みの作品を再開できます。位置は先生が保存した位置を再開するため、必ず閉じる直前の場所へ戻る保証ではありません。
4. 過去へ戻す場合は先生が復元ポイントを選び、「選んだ保存時点へ復元…」を押します。全員の作品・位置へ影響する説明を確認し、「全員のワールドを復元する」で確定します。

教室ごとに最新20件の復元ポイントを保持します。復元は全員への操作です。授業中に戻す場合は事前に生徒へ知らせてください。古い変更番号で復元しようとした場合は拒否して最新状態へ更新します。

Cloudflare D1にアカウント・教室・STL属性・復元ポイント、非公開R2にSTL本体、Durable Objectsに共同教室の最新状態を保存します。ログアウト・退出だけでは作品やアカウントは削除されません。永続データの自動削除や完全削除用の画面は未実装です。データの取扱いは [プライバシー説明](../public/privacy.html) を確認してください。

## 9. うまくいかないとき

- **街は見えるがログインボタンを使えない**：共同教室の設定が未公開、またはAPI接続が失敗している可能性があります。ゲストの街・VR閲覧は継続できます。
- **Googleのボタンが出ない／学校アカウントで拒否される**：Googleログインの通信と校内管理者のアプリ許可を確認してください。Google認証の画面は本人が操作してください。
- **先生のはずが生徒になる**：先生として事前登録したGoogleアカウントか確認します。アバター名を「先生」にすることとは別です。
- **参加できない**：12文字のコード、登録30人上限、ログイン状態を確認します。先生が別の先生の教室へ入ることはできません。
- **同じアカウントの別の端末で接続した**：同じ教室では新しい接続へ切り替わります。古い端末の活動を停止し、必要な端末から「続きを開く」で入り直します。
- **配置が赤い／拒否される**：建物や作品のない別の地面、縮尺、配置範囲を確認します。STLに問題があればCADで修復します。
- **接続が切れた**：配置を停止して再接続を待ちます。応答が不明な操作を繰り返さず、最新の共有状態を確認します。
- **Googleログインの期限が切れた**：2Dへ戻って再ログインします。セッションは8時間です。Googleボタン表示から長く待った場合も、ログイン準備を表示し直してください。
- **VRが重い・気分が悪い**：使用を中止し、先生へ伝えてください。画質・同時に見える作品数・STLの複雑さ・ネットワークを見直します。

## 10. 授業前の確認と未実装

先生は、校内の1台でGoogleログイン→教室作成→生徒アカウント参加→STL配置→保存→再読み込みからの再開を試し、Quest実機で中央パネルの読みやすさ・コントローラー操作・VR/2D復帰・快適性を確認してください。その後に人数を増やします。

ローカル31接続試験やVRエミュレーターの合格は、30台の実機・校内回線・Googleの本物のログイン・Quest装着時の性能確認とは異なります。これらの実機・本番確認は別の完了ゲートです。現時点の公開・検証記録は [VALIDATION.md](../VALIDATION.md) にあります。

パスキー、音声チャット、生徒の登録削除、参加コードの再発行、完全削除用画面、先生間の共同管理、厳密な歩行衝突、全広域への作品配置は未実装です。授業前に学校の個人情報・Googleアカウント・VR利用のルールを確認し、個人情報を作品名や公開Issueへ書かないでください。

## 開発者向け：実ローカル環境の再確認

授業で使う生徒向けの手順ではありません。共同教室の下流を自分のPCで検証するときは、`npm run build`後に`node scripts/school-browser-server.mjs`を起動します。試験先は`http://localhost:4174`で、`127.0.0.1`表記へ置き換えるとOrigin条件が異なります。別ターミナルの`node scripts/verify-school-browser.mjs`が専用Chromeで実UIを操作し、結果を`test-results/school-browser.json`へ保存します。試験終了後はサーバーをCtrl+Cで停止します。

この環境は実際のWorkerと一時D1/R2/SQLite Durable Objectsを使いますが、本人確認には一時DBへ登録した試験セッションを使います。本物のGoogleログイン・本番DB・本物のQuestの試験ではありません。`.cache/school-browser-fixtures.json`には試験クッキーが入るため、内容を公開・ログへ出力・Gitへ登録しないでください。GoogleのパスワードやOTPは使いません。

VRエミュレーターは、4174サーバーを動かしたまま`node scripts/school-xr-dev.mjs`を起動し、`http://localhost:4173/?testxr`から接続します。このローカル専用ブリッジとIWERを本番配信へ含めません。開発者がログイン済み・ゲスト双方を検証しても、先生・生徒の実アカウントでのGoogle本人確認とQuest装着時の確認は別に行います。詳細は[READMEの検証手順](../README.md#17のローカル共同教室ブラウザー検証)と[検証記録](../VALIDATION.md)を参照してください。
