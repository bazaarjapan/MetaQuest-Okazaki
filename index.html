Questを検出：ドローン・モード2で開始します。VR中は左スティック＝昇降・旋回、右＝前後・左右。2D画面の「全画面」と、視界いっぱいのVR表示は別です。狭い画面では「設定」タブから「QuestでVRを見る」を押してください。

WASD：前後左右 / R・F：上下 / Q・E：旋回。左：上下・旋回 / 右：前後・左右。指を離すと停止。

WASD：移動 / Space：上昇 / Shift：下降 / F5：視点。Z長押し：ロケット離陸・加速、離すと滑空 / X：空中停止。画面クリックで見回す・Escで停止。画面下の「移動」でスティックを表示。左で上下と旋回、右で前後左右に移動します。

視点・スマホ・Questの操作を確認

PC・スマホのクリエイティブ風は最初、三人称・後方視点。選んだ未配置STLは手元に表示します。視点ボタンで一人称・三人称を切替。スマホは1本指で見回し、2本指で拡大。「移動」をオンにすると左のスティックで上下・旋回、右で前後・左右に移動できます。Questはモード2で開始し、VRは一人称です。VRは自由移動ONで開始。2D復帰・地点切替・ダイアログ操作では移動OFF。

この教材について

岡崎市2020年度の公式3D都市モデルを軽量化した教材です。約25km×19kmはモデルの収録範囲で、行政区域全体を保証するものではありません。建物の色と窓はゲーム風の装飾です。現在の街や駅内部の完全な再現ではありません。

移動・視点操作・VR・作品づくりはログイン後に使えます。生徒は先生から配布されたID・パスワード、先生は登録済みGoogleアカウントでログインします。参加するとアバター・作品・位置などを保存します。ホスティング事業者・先生のGoogle認証・標高配信元との通信も発生します。

配置・回収・仕上げの操作ガイド

下の10枠でSTLを選び、ホイールでサイズ変更、右クリックで配置、右ドラッグで見回せます。設置済みの枠をクリック・タップすると移動・回収・編集を選べます。街の自分の作品を左ボタン0.8秒長押し（またはR）でも回収できます。緑は配置可能、赤は配置不可、黄色は最後のプレビュー（未設置）です。

手持ちの作品は「この場所に配置」でワールドに置きます。置いた作品は「見た目を保存」で色や仕上げを共有できます。大きさや位置も変えたときは「変更を保存」でまとめて共有します。

作品を選ぶと、ここから配置や変更の保存ができます。
