01 / FOR TEACHERS

先生の準備は、この4つ。

ワールドは1つ。「岡崎 みんなのワールド」に先生と生徒が集まります。教室の作成や招待コードの入力は不要です。

  1. 先生のGoogleアカウントで入る

    街をひらく →「先生としてログイン」→「Googleログインを表示」。先生として登録済みのアカウントを選びます。初回は表示名を決めて「この名前でワールドに入る」を押します。

  2. 生徒のID・パスワードを発行する

    画面右上の「自分の名前 · ログイン中」を押してアカウント画面を開きます。「先生：生徒のIDを発行（最大30人）」で「発行する人数」を入力し、「ID・パスワードを発行」を押します。発行済みを含め最大30人です。

    発行した直後に、安全に控えてください。

    パスワードは発行・再発行時だけ表示されます。後から同じパスワードを再表示できません。

  3. 一人に1組ずつ、安全に渡す

    生徒本人に、参加URL＋本人のID＋本人のパスワードだけを渡します。全員分の一覧をクラス全体に公開しないでください。このマニュアルのURLも一緒に配れます。

    生徒に配る参加URLhttps://metaquest001.gigach.net/

    同じIDを別の生徒へ使い回さないでください。前の持ち主の作品も同じIDに紐づきます。生徒枠の削除・再割当ては未対応です。

  4. 授業の区切りで復元ポイントを残す

    アカウント画面の「先生：クラウド保存・復元」→「授業の状態を保存」。全員の位置・作品の復元ポイントを残します。最新20件を保持します。

ふだんの保存は自動

STLの読み込みや、サーバーで確定した配置はクラウドに保存されます。次の授業も同じIDで続けられます。半透明の配置前プレビューは下書きで、配置としては保存されません。

「復元」は全員に影響します

保存時点を選び「選んだ保存時点へ復元…」→確認後「全員のワールドを復元する」。全員の作品・位置が巻き戻ります。必ず声をかけ、必要なら現在の状態を先に保存してください。

「共同教室・アカウント」→「生徒一覧を確認・更新」で、生徒ごとの配置作品・場所を確認できます。名前・IDで検索し、「作品を配置している生徒だけ」に絞れます。「作品を見に行く」で作品のそばへ移動。「生徒のホットバーへ戻す」で配置だけを解除し、持ち主が同じSTLを再利用できます。作品の色・説明・形の変更は持ち主だけが行えます。

02 / FOR STUDENTS

まずはログインして、街に入ろう。

  1. 先生からもらったIDでログイン

    参加URLを開き「生徒としてログイン」を押します。「生徒：IDで入る」にIDとパスワードを入力してログイン。生徒のGoogleアカウントは使いません。

  2. 初めてのときだけ、名前を決める

    「頭の上に表示する名前」に1〜20文字のニックネームを入れ、「この名前でワールドに入る」を押します。先生・ほかの生徒と同じ名前は使えません。本名やメールアドレスではなく授業用のニックネームを使いましょう。

  3. 街の接続を待ち、3D画面をクリック

    「接続中：共同活動できます」になったら準備完了。PCは最初、キャラクターを後ろから見る視点です。3D画面をクリックして、W で前へ進んでみましょう。画面の向きを変えるときは右ドラッグです。

次回も同じID・パスワードで。

名前・アバターの色・自分のSTL・確定した配置位置・回転・大きさを引き継ぎます。忘れたときは新しいIDを作らず、先生にパスワードの再発行を頼んでください。

ログイン前や接続が切れたときは、移動・視点操作・VR・作品づくりはできません。同じIDを別の端末で使うと、最後に接続した端末へ活動が移ります。

現在地は画面の上部に表示されます。

「JR岡崎駅から 東120 m ／ 北80 m」のように、駅を基準にした位置を確認できます（方角ごとの距離で、道のりではありません）。遠くはkm表示になります。三人称でもキャラクターの位置を表示します。VRではXボタンで開くフィールドノートの上部に表示されます。

マウス・操作モードについて

空手で3D画面をクリックすると、ブラウザーが許可した場合はマウス固定で見回せます。Esc で解除。STLを持つとカーソルで配置場所を選べるようになります。マウス固定が使えなくても、右ドラッグで見回せます。

「メニュー」→「見学」→「移動・視点の操作」でモードを選べます。選択は次回も使います。この早見表はクリエイティブ風用です。従来の「ドローン・見学」はドラッグで回転・ホイールで拡大、自由移動ON時はWASD・R/F上下・Q/E旋回。STLのR回収はクリエイティブ風で使ってください。

04 / MAKE YOUR PLACE

自分のSTLを、街に置こう。

STLは3Dの形のファイルです。授業前に自分の端末へ用意してください。元の街と、ほかの人の作品は変更できません。

まちレーダーで仲間や作品の方向を確認

2D画面右上のレーダーは中央が自分、上が進行方向です。同じ教室に接続中の他の生徒は水色、先生は紫で、移動・退出に合わせて更新します。金色の点は自分の配置作品、青色はJR岡崎駅。範囲外は縁の菱形になります。半径ボタンで100m・300m・1km・5kmを切り替え、「作品一覧」から作品を選んで見に行けます。小さくしたいときは「−」を押します。

展示名と説明をつける

「自分のSTL作品」の上部の一覧で作品を選び、「展示名・説明を編集」を開いて入力・保存します。近くの作品には展示名と作者が表示され、詳細画面で説明を読めます。先に作品が置かれた敷地には、高さを変えても重ねて置けません。

街の見え方・目印へワープ

ESCメニューの「設定」で昼／夕方を選べます。「広域」では地図上の目印を選んで上空へ移動できます。川岸・草地・街灯と、道路上の車・線路上の電車・空の飛行機を表示します。樹木・信号機・建物の窓・乗り物は装飾で、実際の設備・植生・運行情報ではありません。「車・電車・飛行機を動かす」で動きを止められます。「軽量」「航空写真」では装飾を非表示にします。岡崎滑空場の目印は運営団体の公開位置に基づきます。滑走路の詳細な再現ではありません。

足音・飛行音

歩くと足音、飛行すると風とエンジン風の音、高速飛行ではジェット風の音が鳴ります。「設定」の「足音・飛行音」と「音量」で消音・調整できます。最初に画面を操作した後に有効になり、停止中・メニュー表示中・別タブへ移った時には消音します。

  1. 空いている「＋STL」枠をクリック

    画面下の10枠から空き枠を選び、自分の .stl ファイルを開きます。複数選択も可能。読み込んだ原本は自分のIDに紐づいてクラウドに保存されます。

  2. 緑の底面が出る、空いている地面をねらう

    未配置STLは手元の見本と、地面の半透明プレビューで確認できます。緑＝配置可能、赤＝配置不可。建物に重なる場所、空中、地形のない場所には置けません。岡崎の表示範囲全体の空いている地面へ置けます。周辺の地形と建物が読み込まれるまで少し待ってください。黄色の模型は最後のプレビューで、まだ設置されていません。

  3. サイズ・向きを調整する

    設置前に3D画面上でホイールを回してサイズ変更。手元の模型は小さな見本のままなので、地面のプレビューと幅・高さ・奥行き（m）を見てください。全方向に回転したいときは「メニュー」→「見学」→「自分のSTL作品」で「大きさ・回転・配置位置を調整」を開き、X/Y/Z回転と縮尺を調整します。

  4. 右クリックで置き、確定を確認する

    「設置済」となれば完了。通信中は待ち、「サーバーで配置を確定しました」などの成功表示を確認します。置き直すときは自分の作品をねらって左ボタンを0.8秒長押し → 手持ちのまま新しい場所に右クリック。回収してもSTL原本は残ります。

置いた作品を探す・回収する・色を変える

設置済みの枠には「配置済み ⋯」と展示名が表示されます。枠をクリック・タップすると、次のメニューが開きます。右クリック・長押しも使えます。キーボードでは枠にフォーカスしてShift＋F10でも開けます。メニューの外側・Esc・「閉じる」で閉じます。

  • 📍 作品のところへ移動：作品の隣の、安全に立てる地面へ移動して作品を向きます。黄色い枠が目印です。地面と建物の読み込みを最大15秒待ち、安全を確認できないときは移動しません。移動後は停止状態なので、周囲を確認して再開してください。
  • ✋ 回収して手に持つ：自分の作品を色・大きさ・回転を保って回収します。地面をねらい、右クリックで置き直します。
  • 🎨 色・大きさ・回転を変更：詳細画面を開きます。数値調整は「大きさ・回転・配置位置を調整」を開きます。「この色にする」で色だけをクラウドに保存できます。作品全体への単色設定で、STL原本の塗り分け・テクスチャーの復元ではありません。

これらは2D画面の操作です。地面での右クリックは従来どおり「設置」、右ドラッグは「見回す」です。作品の場所はJR岡崎駅からの方角と現在地からの水平距離でも確認できます。

読み込みの向き・単位

初期はCADのZ軸が上・最長辺10mに合わせます。違う場合は「自分のSTL作品」で単位・上方向を設定してから読み込んでください。STL形式自体には写真テクスチャーは含まれません。

保存のチェック

STLの原本保存と、地面への配置確定は別です。設置済みの作品は次回も同じ場所・色で表示されます。回収後は手持ちの下書きになるため、ログアウト・再読み込み前に置き直してください。下書きの場所・色・変形は保存されませんが、クラウドのSTL原本は残ります。

読み込めるサイズ・数の上限
  • 1人につき最大10ファイル、合計25MiB。1ファイルは6MiB・2万三角形まで。
  • 1枠につき同時に1作品、1人最大10点。原本を消して空き枠を作る機能は未対応です。
  • 作品の幅・高さ・奥行きは各100mまで。大きすぎるときは縮小してください。
  • 全員の作品合計は最大340点・20万三角形。三角形数の制限に先に達する場合があり、全員が重い模型を10点ずつ置ける保証ではありません。

05 / META QUEST

VRは、ドローンのモード2。

Questのブラウザーで同じ参加URLを開くと、ドローン・モード2が自動で選ばれます。ウィンドウの大きさや過去のPC用設定にかかわらず、ページを開いたときはこのモードで開始します。PC・Macはクリエイティブ風が初期設定（自分で保存した選択は維持）です。

視界いっぱいに街を表示したいとき

ログイン後「メニュー」→「QuestでVRを見る」を押し、ブラウザーの確認が出たら許可します。小さいウィンドウでは「メニュー」→「設定」にVRボタンがあります。これはVRの立体空間に入る操作です。自動では入らないので、自分でボタンを押してください。

2Dのまま画面を大きくしたい場合は「メニュー」→「見学」→「全画面」。ブラウザーが対応している場合に、このページの表示を広げます。2Dの全画面とVR表示は別で、2D全画面だけでは視界全体の立体表示にはなりません。

  1. 2Dのブラウザー画面でログイン。初回は名前を決め、街への接続を待ちます。
  2. STLを使う場合は、Quest内に用意したファイルを2D画面で先に読み込みます。
  3. 「メニュー」→「QuestでVRを見る」（狭い画面は「設定」タブ）。安全なプレイエリアで開始します。
  4. VRは自由移動ONで開始・再開します。開始時にスティックを倒していたら一度離してください。Bボタンで停止・再開。少し倒すとゆっくり、大きく倒すと速く動き、離すと停止します。

左スティック：上下＝上昇・下降、左右＝旋回。右スティック：上下＝前進・後退、左右＝横移動。今見ている水平の向きに進みます。頭を左右に向けると進行方向も変わります。上下を見ても勝手に昇降せず、高さは左スティックで操作します。真上・真下を見たときは直前の水平の向きを保ちます。倒し続けた時間ではなく倒す角度で速度が変わります。

VR中のログイン・ファイル選択はできません。いったん2Dへ戻ってください。画質変更も2Dで行います。VRは機器の年齢・利用条件と先生の指示に従い、安全な範囲で使用し、不快感があればすぐ外してください。

06 / PHONE & TABLET

スマホ・タブレットで使う。

  • ログイン：PCと同じID・パスワードを使います。名前や作品も同じです。
  • メニュー：画面下の「見学」「広域」「設定」で開閉します。
  • 見回す：移動OFFのときに1本指で画面をドラッグ。後方・前方視点では2本指でカメラの距離を調整できます。
  • 移動：画面下の「移動」をON。左の仮想スティックで上下・旋回、右で前後・左右。指を離すと止まります。
  • STL：「自分のSTL作品」の詳細パネルで選択・調整・地面指定・配置確定を行います。PCのR回収はタッチ長押しでは代用しません。配置を取り消すときは詳細パネルで自分の設置済み作品を選び「ホットバーへ戻す」（配置だけを解除。STL原本は残る）を使います。

PC・Questと操作が異なります。授業前に使用する端末とブラウザーで、先生と一緒に確認してください。

07 / HELP

困ったときは、ここから。

ログインしたのに動けない
  1. 初回の名前登録が終わっているか確認。
  2. ワールドが「接続中：共同活動できます」になるまで待つ。
  3. アカウント画面・メニューを閉じ、3D画面をクリックする。
  4. 自由移動がOFFなら「見学」でON。QuestはBボタン。

通信切れ・別画面・2D復帰の後は安全のため停止します。VRへ入り直すと中立のスティックを確認してONで開始します。接続が戻っても勝手に動き出しません。操作を再開してください。

生徒がパスワードを忘れた

先生がアカウント画面の「生徒一覧を確認」から本人を探し、「パスワード再発行」。新しいものを本人にだけ渡します。旧パスワード・旧セッションは無効になりますが、名前・STL・配置は残ります。生徒は同じIDと新しいパスワードで入り直します。

先生のGoogleログインができない

登録済みの先生アカウントか確認し、「Googleログインを表示」から選び直します。学校のブラウザー・ネットワークでGoogle認証やこのサイトのCookieが制限されていないか管理者に確認してください。連打せず、表示されたエラーを控えて先生・管理者へ相談します。生徒はGoogleではなくID・パスワードを使います。

「その名前は使われています」と出る

先生・生徒で名前は重複できません。英字の大文字・小文字や前後の空白では区別できないので、別のニックネームにします。名前変更で作品は消えません。メールアドレスは名前に使えません。

STLが赤くなり、置けない・見つからない

読み込み済みの空いている実地面をねらってください。建物・他の作品との重なり、大きさ、配置範囲を確認。遠い広域でも近づいて周辺の読み込みを待つと置けます。模型が大きすぎるときはホイールで縮小し、裏側に隠れていないか右ドラッグで見回します。設置済みの枠は、先に自分の作品を左長押しで回収してください。

自分以外の作品、建物の奥に隠れた作品は回収できません。STLが重すぎる場合は元の制作アプリで形を簡略化してください。

画面が重い・道がぼける・酔いそう

「メニュー」→「設定」→「画質」を「標準」または「軽量」へ。標準・高精細のゲーム風表示では、近くの道路・線路・白線を地図の線から作った面で表示します。地形に沿わせるため、画像の拡大より輪郭が鮮明です。遠くは軽い地図表示に切り替わります。元データにない細部は再現できません。通信が落ち着くまで少し待ち、STLの数や複雑さを抑えてください。

Questで気分が悪くなったら、すぐにVRを終了して休憩。無理に続けず、先生に伝えてPC表示へ切り替えましょう。

迷子になった・街が写真のまま

「メニュー」→「見学」→「開始地点に戻る」。QuestはYボタンでも戻れます。ゲーム風の見た目にするには「メニュー」→「設定」→「街のデザイン」でゲーム風を選択。古い表示ならページを再読み込みします。PCは Ctrl + F5（Macはブラウザーの再読み込み）を使います。下書きは先に確定してください。

次の授業で作品が見つからない

前回と同じIDで入っているか確認します。確定していない下書きは残りません。先生が過去の保存時点へ復元した場合は、その時点の配置に戻っています。アカウントを作り直さず、先生と一緒に確認してください。

08 / BEFORE CLASS

授業前のチェックリスト。

まず2〜3台で練習。そのあと実際に使う台数で確認しましょう。

チェックはこのページを開いている間の目印です。クラウドには保存しません。印刷して配布することもできます。

45分授業の進め方の例

  1. 0〜10分 ログイン・名前登録・操作練習
  2. 10〜20分 駅の東西を観察し、空きスペースを探す
  3. 20〜35分 用意したSTLを配置・調整する
  4. 35〜45分 お互いの作品を見て発表・先生が状態を保存
実装済みの範囲を確認して使ってください。

生徒最大30人＋先生4人の接続枠がありますが、実教室30台での速度・Quest実機の快適性を保証するものではありません。音声会話・チャット・パスキー・生徒枠の削除／再割当ては未対応です。2020年度のPLATEAUを元にした教材で、建物の色・窓や地面のゲーム風表現は装飾です。現在の街・駅内部・橋の高さを完全再現するものではありません。
