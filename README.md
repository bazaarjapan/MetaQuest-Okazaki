# 岡崎駅 フィールドノート — 授業向け WebXR MVP 1.10.5

1.10.5：VR開始・再開時は自由移動ON（両手の追跡・視点が有効になり、スティックとボタンを離してから）。右スティックの前後・横移動は今見ている水平の向きに追従します。左スティックの昇降・旋回、倒す角度に比例する速度、Xメニュー表示切替と長押し退出は維持。上下を見ても水平速度は変えず、真上・真下では直前の水平向きを保持。中断・追跡喪失・コントローラー切断・ログイン切れでは停止し、勝手に再開しません。2D画面は従来どおりです。

1.10.4：VRのX短押し（離したとき）で中央メニュー全体を完全に非表示・再表示します。縦方向の縮小は行わず、元の大きさ・タブ・作品選択を保持。非表示中は光線でもクリックできず、Xの1.5秒長押しによる2D復帰は引き続き使えます。VRへ入り直すとメニューを表示して開始します。

1.10.3：Quest Browserでは2D画面でもドローン・モード2で開始します。過去のクリエイティブ設定より端末初期値を優先し、PC/Macの保存済み操作設定は上書きしません。狭いウィンドウでも同じです。Questの自由移動は初期OFFで、VRではBで開始・停止。端末のUAヒントは操作初期値だけに使い、VR可否はWebXRの実行時検出を維持します。全画面2DとVRの違い・開始手順は `/manual/#quest` に掲載。

1.10.2：駅周辺の写真付き・黒材質・小さな建物もゲーム風の対象に統一。元の地面は対象外で、建物の形状・位置・UV・写真データは保持します。ゲーム表示では元写真のサンプリングを省略し、写真表示では元の色・画像をそのまま使います。

近景LOD：元の地理院ベクトルから駅周辺24枚の1024pxパッチ、広域154枚の2048px画像を直接描画。高精細では近くの1枚だけを重ね、遠景は512px（最大8区画）を維持します。近景・遠景のGPU画像合計は32MiB以内（駅の常駐アトラス・描画バッファ等は別枠）。標準は近景を最大1024px、軽量は近景を停止します。地形の三角形をUVで切り出すため元地形と一致し、地面未取得時は近景を捏造しません。画像失敗時も遠景と接地面を保持します。写真表示では近景LODを停止します。

接地：クリエイティブ飛行中も既知の地面を下限にし、移動範囲制限後に高さを再取得します。足の幅を含む5点を調べ、地形の後読み込み時もログイン済みの自分の足を上方に補正します。歩行・走行アニメーションで脚の角が足元より下へ出る分も補正します。

公開先： https://metaquest001.gigach.net

授業用の図解マニュアル： https://metaquest001.gigach.net/manual （先生のID発行・保存、生徒のログイン、PC操作早見表、STL配置、Questモード2、スマホ、トラブル対応、印刷）。ログイン画面と「使い方」からも開けます。個人のID・パスワードは掲載しません。

1.10は、国土地理院最適化ベクトルタイルの道路・鉄道・水域を描いた「ゲーム風」を初期表示にします。地面の草模様と建物の色・窓は見やすさのための装飾です。「設定 → 街のデザイン」で航空写真へ戻せます。元の地形と建物の位置はそのままで、駅周辺＋広域154地形区画に適用します。地図は事前作成したWebPを配信し、追加の3D三角形やプレイヤーから地図APIへの通信は発生しません。広域のテクスチャは近隣のみ読み込み、32MiBの上限内で破棄します。橋の高さ・道路標示の厳密な再現やボクセル地形ではありません。

地図出典：[国土地理院最適化ベクトルタイル](https://github.com/gsi-cyberjapan/optimal_bvmap)。原データのタイルごとのSHA256と加工内容は `public/field/manifest.json` に記録します。`npm run build:field` で再生成、`npm run check:assets` で335枚すべてのハッシュ・寸法・収録区画を検査します。駅周辺の基本画像は軽量768×512・標準1536×1024・高精細3072×2048に切り替わります。写真・PLATEAU原モデルのファイルは上書きしません。

1.9.3では先生・生徒共通の表示名重複防止を追加しました。初回のみ名前を登録し、以降は同じIDで名前・STL・配置を再開します。`0003_unique_avatar_names.sql` は既存の重複名の後発アカウントを名前再登録待ちにしますが、ID、資格情報、所属、STL、配置データを削除しません。原子的なUNIQUEインデックスで同時登録も拒否します。本番更新はD1のTime Travel bookmarkを記録し、移行前後のデータ数を照合してから行います。

PCで3Dを観察し、対応するQuest BrowserではWebXRでVRへ入れる教材です。街の操作にはログインが必要です。1.8は1つの共通ワールドに、指定Googleアカウントの先生と、先生が発行したID・パスワードの生徒が入ります。生徒30人＋先生4人、初回ニックネーム、10枠STLホットバー、左クリック配置、Rキー回収、底面プレビュー、Escメニューを提供します。Unity APK版・元PLATEAUは変更しません。最新の手順は [先生・生徒ガイド](docs/SCHOOL_GUIDE.md)。旧個別ワールドは保管し、自動統合しません。

授業の使い方は[先生・生徒の共同教室ガイド](docs/SCHOOL_GUIDE.md)、データの取扱いは[プライバシー説明](public/privacy.html)にまとめています。開発状況は[親Issue #3](https://github.com/bazaarjapan/MetaQuest-Okazaki/issues/3)で追跡しています。実装済みと本番公開・Google実ログイン・学校の30台・Quest実機確認は別のゲートです。公開コミットと実施した試験は[VALIDATION.md](VALIDATION.md)を確認してください。パスキーは未実装です。

## 実装

- 国土交通省PLATEAU 岡崎市2020年度のJR岡崎駅周辺。5メッシュ、58,845三角形。
- 駅周辺の詳細モデルを常に保持し、2020年度の岡崎市建物モデル収録範囲へ拡張。範囲は約25.1km × 19.4km、追加データは約213,083棟相当・770区画です。この長方形はデータの収録範囲で、岡崎市の行政界全域を完全に覆う保証はありません。広域部分の建物は外形だけのLOD1で、建物写真はありません。
- 広域マップをクリックするか、建物がある区画を選んで上空へ移動できます。QuestのVR中も中央パネルの「広域」から地図を光線・トリガーで選べます。YでJR岡崎駅に戻れます。
- 周辺区画だけを読み込み、遠くなった区画をメモリから解放するストリーミング方式。画質に応じた建物の常駐上限は軽量16・標準25・高精細36区画、地形の常駐上限は9・9・16区画です。描画予算によって、それより少なくなることもあります。
- 3つの見学地点、観察の問い、開始地点への復帰、使い方、先生向けページ。
- PC：3D画面と「見学」「広域」「設定」のタブ式サイドパネルを1画面に配置。初回はクリエイティブ風・自由移動ONで開始します。操作モードと自由移動の切替は「見学」タブの先頭です。3D画面をクリックするとマウスで見回せますが、自動でマウス固定や移動は行いません。保存済みのモード選択を優先し、従来のドローンにも切り替えられます。タブを切り替えて必要な操作だけを表示します。
- スマートフォン：最初は街が見える状態で、下部ツールバーから必要なパネルを開閉。タッチで回転・ピンチで拡大し、自由移動をオンにすると左右の仮想スティックでモード2飛行ができます。左は上下移動・旋回、右は前後・横移動。指を離す・操作がキャンセルされると入力を0に戻して停止します。
- Quest：没入型VR、頭の追従、コントローラー光線とトリガーによるパネル選択。
- VRは中央の1枚の「岡崎まち フィールドノート」に案内・2D復帰・左右のコントローラー状態を集約。「見学」「広域」「作品」を同じパネル内で切り替えます。大きなボタンへ光線を合わせると強調され、トリガーで選べます。Xを短く押して離すとメニュー全体を非表示・再表示します。押した瞬間ではなく、短押しの解除時に切り替わります。
- VRの光線は左が水色・右がオレンジ。太い線がパネル面で止まり、丸い先端とボタンの枠で狙った場所を示します。両手の照準を同時に表示し、作品も左右どちらかのトリガーを1回押して選べます。隙間・無効ボタン・操作停止中には実行せず、押し続けても自動連打しません。スティックの倒し量による移動操作とは別です。
- 中央パネルの大きな「2Dに戻る」はメニュー表示中の全タブで使用できます。光線とトリガー、またはXを1.5秒押し続ける操作で、ページを再読み込みせずVRから通常の2D画面に戻れます。メニュー非表示中も長押しで戻れますが、進捗はメニュー表示中だけ見えます。戻った後の「VRに戻る」で見学を再開でき、見学位置・水平の向きを引き継ぎます。VRへ入り直したときの頭の上下方向・傾きは自然な頭の追従を使い、PCカメラの角度に固定しません。2Dへ戻るときは自由移動をオフにし、VRへ入り直すときは中立のスティックを確認してONにします。
- 中央パネル内のグラフィカルなコントローラー表示（HUD）：スティックの位置・倒し量、X/Y・A/Bの押下と接触、トリガー・グリップの握り量、接続状態、自由移動ON/OFF、上下・水平の移動速度。移動OFFでも入力を表示しますが、実際の移動速度は0です。グリップは状態表示のみで、加速ボタンではありません。PC画面には従来どおり左右下のQuest操作プレビューが出ます。VRでは別の左右下パネルは出しません。
- Aで次の地点、Bで自由移動ON/OFF、Yで東側へ戻る。Xは短く押して離すとメニュー表示切替、1.5秒長押しで2D画面へ戻ります。VRの初期値は自由移動ON。モード2飛行（左：上下・連続旋回、右：前後・横移動）。旋回は最大30度/秒、移動方向は今見ている水平の向きに従い、上下方向は左スティックだけで操作します。
- スティックの倒し量に比例した速度：水平最大12m/s・上下最大6m/s。中心付近はデッドゾーン0.18、残りの倒し量を線形変換。保持時間による加速・惰性はなし。斜め入力は水平最高速を超えない。離す・B停止・入力切断で即停止。地点を選ぶ、XRセッションが非表示になると自由移動はオフ。B再開はその場で行う。
- 初期画質は「高精細」。MVP 1.4では旧版の画質設定を引き継がず、高精細で開始します。その後に選んだ画質を新しい設定キーでブラウザー内に保存します。保存が禁止された環境や無効な設定値の場合も「高精細」で起動します。
- 先生はGoogle、生徒は発行されたID・パスワードでログインして参加します。初回にニックネームを決めた後は自動参加し、次回も同じアバター・作品で続けます。ログイン前は移動・視点・VR・作品操作を利用できません。
- 先生は生徒30人分まで発行・再発行できます。パスワードは144ビット乱数、salt付きハッシュのみ保存。旧パスワードの再表示はできません。再発行は全旧セッションを失効させ、作品を保持します。IDの別の人への再割当ては行いません。
- ブラウザ内に保存する設定は画質・PC操作モードです。認証はSecure・HttpOnlyセッションを使い、Googleトークンをブラウザstorageへ保存しません。D1に本人識別・教室・STL属性・復元ポイント、非公開R2にSTL本体、Durable Objectsに最新共有状態を保存します。広告・独自の行動解析・音声チャットは実装していません。Cloudflare・Google・国土地理院との通信は発生します。詳しい保存期間・削除の制限はプライバシー説明を参照してください。
- ネット接続が必要。広域へ移動すると追加データを読み込み、広域地形の標高は国土地理院の公式タイルをリアルタイムに取得します。オフライン保証、元の街の編集、厳密な歩行・壁衝突、現在の街や駅内部の完全再現は未実装です。STL配置は実地形・建物を確認できる駅周辺に限定します。

## STL作品を配置する（1.8・共通ワールド）

通常は10枠のホットバーまたは1〜9・0で選択→空き地をねらい左クリック→自分の作品をRキーで回収。Escで右メニューを開閉し、画面クリックで閉じてPC移動を再開します。以下の詳細操作も残しています。

PCの初回はクリエイティブ風・自由移動ONです。「見学」先頭で操作モードと自由移動を切り替えられ、保存済みのモード選択は次回も使います。ONにしただけでは位置を変えず、マウス固定も行いません。3D画面をクリックするとマウスで見回せます。WASDで移動、同じW/A/S/Dを350ms以内に二度押しして2回目を保持すると1.5倍速、Ctrlでも1.5倍速です（倍率は重ねません）。Space上昇、Shift下降、Space二度押しで飛行/歩行切替、F5で一人称→アバター後方→前方、Escでマウス解除です。モード変更・地点変更・共有位置の復元・ダイアログ・画面から離れたときは移動OFFになり、閉じるだけでは再開しません。フォームやダイアログ操作中は移動せず、F5で作品を失う再読み込みもしません。壁衝突は未実装なので歩行シミュレーターではありません。スマホは初期OFFのドローン/仮想スティックを維持し、Questは常にモード2です。VRへ入る際の位置は後方カメラではなくプレイヤーの眼を基準にし、2Dへ戻るときは安全な一人称・移動OFFで復帰します。読み込み中に画面を離れたりダイアログを開いた場合も、初回ONで安全停止を上書きしません。

1. 2D画面で先生はGoogle、生徒はID・パスワードでログインします。初回の名前登録後に自動参加します。ログイン前はログイン画面だけ操作できます。移動・視点操作・VR・STL操作はログインと接続完了後に解放され、ログアウト・通信切断時は停止します。
2. 上方向をCADで一般的なZ軸、またはY軸から選びます。STL自体には単位情報がないため、大きさは「最長辺10m」「元データmm」「元データm」を明示的に選びます。
3. ASCII/バイナリSTLを複数読み込めます。1ファイル6MiB・2万三角形、1人10ファイル・25MiB・同時10配置、全体340配置かつ20万三角形まで。複雑さの上限が先に適用される場合があります。破損・非有限座標・潰れた三角形を拒否します。共通ワールドは1ファイルにつき1配置です。
4. 作品を選び、東西X・南北Z、縮尺、XYZ各軸の回転角を調整します。「地面をクリックして移動」でも配置位置を選べます。底面は駅周辺の実地形に吸着します。
5. 赤い下書きは未配置です。元の建物に重なる・実地形がない・駅周辺からはみ出す場合は確定できません。回転した作品の水平包囲矩形で保守的に判定するため、狭い隙間へ置けない場合があります。
6. 「配置を確定」でサーバーが所有者・最新変更番号・実地形・建物と既存作品を再確認し、成功した配置だけを教室全体へ共有します。元PLATEAUと元STLファイルは変更しません。他の参加者の作品は先生でも直接編集できません。「作品を削除」は配置を削除する操作で、アップロード済みのSTL本体をR2から消す操作ではありません。

アップロード済みSTLと確定した作品はクラウドへ保存します。未確定の下書きは共有せず、ページ終了・ログアウト等で破棄します。STLは色/テクスチャ情報を持たないため、作品は単色表示です。VRでは中央パネルの「作品」で自分のSTLを選び、XYZ回転・拡大縮小・地面への配置・確定を操作できます。Googleログインと新しいファイル選択は2Dへ戻って行います。

先生は「授業の状態を保存」で全員の作品・位置をD1の復元ポイントへ保存し、最新20件から全員へ復元できます。次回は同じGoogleアカウントで同じ教室を「続きを開く」から開きます。最後の操作位置が常時保存される保証ではなく、位置の再開は先生が保存した位置を使います。永続データの完全削除用画面・参加コードの再発行・パスキーは未実装です。

## 広い地域を見る

1. 最初にJR岡崎駅周辺が表示されます。PCでは「広域」タブを開き、「岡崎市 広域マップ」で観察したい位置をクリックします。スマートフォンでは下部ツールバーの「広域」からパネルを開きます。建物のある場所へ確実に移動したい場合は区画を選び、「選んだ区画の上空へ」を押します。
2. 移動先の上空へ移り、近くの建物と地形を順次読み込みます。読み込み中は少し待ってください。全域を一度にメモリへ載せる方式ではありません。
3. QuestではVRに入った後、中央パネルの「広域」から地図へコントローラーの光線を合わせ、トリガーで行き先を選びます。その後は既存のモード2操作で観察できます。速度はスティックの倒し量で変わり、保持時間による加速はありません。
4. PCのHome、またはQuestのYでJR岡崎駅の開始地点へ戻れます。読み込み先の地形が欠けた場合も、元の駅周辺モデルはそのまま利用できます。

広域の建物バイナリの総容量は122,539,472 bytes（約116.9 MiB）です。これは全770区画の合計で、初回読み込み量ではありません。国土地理院の広域地面写真はz14・256 × 256のタイルごとに使います。駅付近の高解像度写真とは細かさが異なり、高精細設定でも広域の建物に窓・看板の写真が増えることはありません。

学校では本サイトに加え、`https://cyberjapandata.gsi.go.jp`へのHTTPS接続を許可する必要があります。国土地理院の通信が失敗したり、標高のない地点があったりする場合は、該当する広域地形を表示しません。標高を0に置き換えて架空の平地を作ることはありません。利用できる駅周辺や、読み込めた区画で観察してください。

## PC・スマートフォンの画面と操作

PCではモデルと操作パネルが同じ画面に並びます。「見学」は先頭に操作モード・自由移動ON/OFF、その下に駅周辺の地点と観察の問いを表示します。「広域」は地図と区画選択、「設定」は画質です。VRへの入口はパネル下部に表示します。狭い画面や文字を大きくした環境では、パネルの中をスクロールして操作できます。

スマートフォンでは街並みを広く見られるように、操作パネルを初期状態で閉じています。下部ツールバーから「見学」「広域」「設定」を選ぶとパネルが開き、閉じると街全体の表示へ戻れます。「移動 OFF」を押してオンにすると、左右下の仮想スティックを使えます。もう一度押すと停止。パネルや使い方を開いている間も移動を停止します。スマホ表示でのVR入口は「設定」の中にあります。

- 左スティック：上下で上昇・下降、左右で旋回。
- 右スティック：上下で前進・後退、左右で横移動。
- 小さく倒すとゆっくり、大きく倒すと速くなります。保持時間による加速はありません。
- スティックから指を離す・入力がキャンセルされると、そのスティックの入力は0に戻ります。自由移動をオフにすると移動を止められます。

自由移動がオフのときは、モデル上のドラッグで回転、ピンチで拡大・縮小します。誤操作を避けるため、仮想スティックの操作をモデルの回転・拡大操作として扱いません。スマートフォンでは通常の3D観察を利用できますが、没入型VRは対応端末・ブラウザーでのみ利用できます。

## QuestのVRから2D画面に戻る・入り直す

1. VR中は中央パネルの「2Dに戻る」にコントローラーの光線を合わせ、トリガーを押します。メニュー非表示中はXを短押しして再表示するか、そのままXを1.5秒長押しして戻ります。
2. ボタンを使わない場合は、左コントローラーのXを1.5秒押し続けます。進捗リングが完了すると2D画面へ戻ります。短く押して離した場合はガイドの表示だけを切り替えます。
3. 同じページの2D画面へ戻り、現在の見学位置と見ていた方向を引き継ぎます。ページの再読み込みはしません。自由移動はオフになり、止まった状態で確認できます。
4. 再開するときは「VRに戻る」を押します。2Dで確認した見学位置・水平の向きを引き継ぎ、追跡が有効でスティックを離していれば自由移動ONで始まります。Bで停止・再開。頭を上下に向ける・傾ける動きはそのまま追従し、頭の角度をPCカメラに合わせて固定することはありません。

これは表示モードの切り替えで、ページを離れたり、街のデータを初期化したりする操作ではありません。学校では街の閲覧に公開URLを、共同教室には先生の招待URL・コードを配布できます。ログイン済みの同じ教室ではVR/2D間で共同活動を継続できます。ページを閉じて再開する場合は同じアカウントでログインして教室を選び直してください。未確定の下書き・閉じる直前の見学位置の保存は保証しません。

## 画質の選び方

「設定」の「画質」で選択します。初期設定は「高精細」です。MVP 1.4では保存先の設定キーを更新し、旧版の画質設定を引き継がず高精細で開始します。旧版の保存値自体は書き換えません。その後に「標準」や「軽量」を選ぶと、次回もその選択を使います。ブラウザーへの保存ができない場合や設定値が無効な場合は、高精細に戻ります。

画質はVRに入る前に選びます。VR中は変更できません。変更するときは「2D画面に戻る」で通常画面へ戻り、画質を選び直して読み込みが終わってから「VRに戻る」を押します。高精細で動きが重い・不快に感じるときは、標準または軽量へ戻してください。高精細を既定にしたことは、すべての端末で滑らかに動くという保証ではありません。

| 設定 | 地面の空中写真 | VR描画解像度の倍率 | 斜め方向の写真フィルター | 建物の影・輪郭 |
|---|---|---:|---:|---|
| 軽量 | 元の768 × 512画像 | 0.85 | 最大2倍 | 影なし・輪郭なし |
| 標準（くっきり） | 1536 × 1024画像 | 1.0 | 最大4倍 | 影なし・輪郭あり |
| 高精細 | 3072 × 2048画像 | 1.2 | 最大8倍 | 静的な影・輪郭あり |

国土地理院の実際の高ズーム空中写真タイルを地理的に同じ範囲で合成しています。低解像度画像を単に拡大したものではありません。斜め方向のフィルターは異方性フィルタリング（anisotropy）で、端末の対応上限に制限します。高精細は標準に対してVRの要求ピクセル数が約1.44倍になり、地面の写真と静的な影にも処理・メモリが必要です。端末・ブラウザーによって実際の表示や性能は変わります。

上の画像サイズと建物の影・輪郭は、主に元のJR岡崎駅詳細モデルについての設定です。広域部分では読み込む周辺区画数も変わりますが、LOD1の建物写真が新たに付く設定ではありません。広域の描画・読み込み負荷は地点の建物密度やネットワーク速度にも左右されます。

影は固定の光源から事前に描画する静的な影で、毎フレーム計算し直しません。画質変更時は不要になった地面テクスチャを破棄し、HUDの描き直しも変化時・最大15回/秒に抑えます。追加の写真が取得できない場合は、元画像に戻して表示します。

**画質設定は元の建物モデルにない情報を増やすものではありません。** 写真のない白い建物に実際の窓や看板を追加したり、駅内部を再現したりはしません。建物の形状はPLATEAU 2020年度のままです。

広域データの再生成は次のスクリプトを使います。ネット接続が必要です。

```powershell
node scripts/build-region-buildings.mjs
node scripts/build-region-terrain.mjs
```

公式PLATEAUの岡崎市2020年度LOD1データを同じ平面直角座標系へ変換し、建物を区画に分割、頂点共有・量子化で軽量化します。広域地形は各写真タイルに17 × 17の格子を作り、元の駅周辺地形と重なる範囲を切り抜きます。配布する地形はx/z座標・UV・高さ0のテンプレートだけで、DEMの原画像や加工標高値は配布しません。ブラウザーで公式標高PNGを直接取得し、RGBの符号付き24ビット値を0.01m単位へ変換、境界を共有した補間で高さを設定します。NoDataは0mと区別します。

`.cache/region`の元資料・検証用DEMは開発時だけ利用し、公開しません。`public/region/buildings.json`・`terrain.json`には出典、座標範囲、区画参照、ファイルSHA、加工方法を記録します。元の2020年モデルと現行の国土地理院DEMでは、取得・更新年月や高さが完全に一致する保証はなく、厳密な測量整合が必要な用途には使えません。

### GitHubのCIとCodexによる公開

`CI`ワークフローは、全ブランチ宛てのPR、`main`へのpush、手動実行（`workflow_dispatch`）で起動します。`Verify`でNode.js 22を使って`npm ci`・テスト・アセット検証・本番ビルド・`check:production`を実行します。GitHub Actionsは検証だけを担当し、`main`へのpushでも本番へ自動公開しません。`main`の検証済みビルドアーティファクトは保存し、Codexも確認・利用できます。

公開が依頼範囲に含まれる場合だけ、CodexがPRのsquash merge後にマージ済み`main`・リモート一致・cleanな作業ツリー・最終CI・レビュー対応を確認します。その同じコミットをローカルで再検証・ビルドし、`npm run deploy`でCloudflareへ公開します。配信後は全公開ファイルのSHA-256、セキュリティヘッダー、404と必要な操作を確認します。公開前にサイトが新しい版へ更新されたと扱わず、CI合格と公開成功を分けます。

GitHubへのCloudflare Secrets登録は不要です。認証情報はCodexの公開実行環境で管理し、リポジトリやPRへ載せません。詳しい公開ゲートと手順は[CONTRIBUTING.md](CONTRIBUTING.md#codexによる本番公開)、CIの実行結果は[GitHub Actions](https://github.com/bazaarjapan/MetaQuest-Okazaki/actions)を参照してください。

## キャラクターとロケット翼（1.9）

PCのクリエイティブ風モードでは、静止時は手足が止まり、通常移動は歩き、Ctrl／WASD二度押しの高速移動は走るモーションになります。背中に沿って中央で合わさるカブトムシ風の緑色の外羽・半透明の翅脈付き内羽と推進器は全員の標準装備です（Minecraftの素材は使いません）。Z長押しで離陸・加速、離すと滑空、マウスで方向を変えます。マウス固定が使えないブラウザーでは、3D画面を右ドラッグすると左右旋回・上下の向きを変えられます。方向転換のドラッグではSTLを設置しません。Xで翼を畳んで空中停止し、通常の自由移動に戻ります。地面に降りると歩行へ戻ります。推進速度は最大80m/s、燃料制限はありません。飛行中もSpace長押しで上昇できます（Zと同時押し可能）。ロケット飛行・滑空中はSpaceを350ms以内に2回押し、2回目を保持すると上昇補助が12m/sから36m/sになります。離すと高速上昇を解除し、歩行には切り替わりません。WASD／Shiftの通常移動はXで停止してから使ってください。壁衝突は未実装です。

動作の種類は認証済みの位置通信に小さな識別子として添え、同級生にも共有します。位置更新が途切れたらモーションと噴射は停止します。保存・再ログイン時に飛行は再開しません。Esc・入力フォーカス喪失・ダイアログ・VR入場でも停止します。VRの操作は従来のドローンモード2を維持し、Zロケット飛行はPC専用です。羽は閉じた外羽と、飛行時に開いて軽く羽ばたく内羽を切り替えます。20メッシュと2本の翅脈描画で4形状・10材質を共有し、外部モデルやテクスチャーは追加しません。
